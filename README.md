Project Overview

Name of Project  : The Command-Line Banking System
Programmer       : B. Dlalisa
Date             : 20 November 2026

The Command-Line Banking System is a console-based C++ application designed to simulate core retail banking operations. 
It is built using fundamental structured programming constructs—parallel arrays, iterative loops, conditional decision statements, and 
modular functions—the application authenticates account holders and provides real-time balance inquiries, cash deposits, withdrawals, 
account transfers with comprehensive input validation.

The user is given six options to choose from, namely:
     1. Deposit
     2. Withdrawal
     3. Send Cash
     4. Check Balance
     5. Customer Information
     6. Exit

This application is developed using C++ programming language.
